Set up in a minute.

  1. Download

    Choose Mac Apple silicon, Mac Intel, or Windows x64. On a Mac, open the DMG and drag Apple TV Remote to Applications. On Windows, run the EXE installer.

  2. Open it

    Mac: builds are not notarized. After trying to open the app, System Settings → Privacy & Security may offer Open Anyway. Windows: SmartScreen may show an “unrecognized app” warning; More info → Run anyway may be offered.

    These are not Apple- or Microsoft-trusted OS builds. Updater signatures are separate from OS code signing. Only proceed if you trust the source and downloaded from this project's GitHub release. Don't bypass your organization's security policy.

  3. Pair

    Pick your Apple TV and type the code it shows on screen. Your computer and Apple TV need to be on the same local network. Guest Wi-Fi, VPNs, or client isolation can prevent discovery. No Apple ID password is needed.
