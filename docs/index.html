Set up in a minute.

  1. Download

    Get the installer. On a Mac, drag Apple TV Remote to Applications. On Windows, run the installer.

  2. Open it

    The first launch shows a warning. Mac: System Settings → Privacy & Security → Open Anyway. Windows: More info → Run anyway. Why the warning?

  3. Pair

    Pick your Apple TV and type the code it shows. Typing and apps ask for a second code the first time.

Questions.

Can I control an Apple TV from a Mac or Windows PC?

Yes. Apple TV Remote is a menu bar app for macOS and Windows that controls an Apple TV on the same network: navigation, playback, volume, typing, and opening apps. No Apple ID is needed.

Is it free?

Yes. It is free and open source under the GPL-3.0 license, with no account or subscription.

What does it run on?

macOS 13.5 or later, on Apple silicon or Intel, and 64-bit Windows.

Why does my computer warn me when I open it?

The builds are not notarized by Apple or signed for Windows, so macOS and Windows flag them as unverified. Updates are signature-verified separately. Only continue if you downloaded the installer from this project's GitHub release, and don't bypass your organization's security policy.

Why can't it find my Apple TV?

Your computer and Apple TV must be on the same local network. Guest Wi-Fi, VPNs, and client isolation block discovery.

Where are my pairing keys kept?

Only on your computer: in a file readable by your user account on a Mac, and in Credential Manager on Windows.

Free and open source.

Reports are public, so leave out pairing keys, PINs, backups, and network details.
